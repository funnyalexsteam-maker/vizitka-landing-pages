# Чек-лист: лендинг готов к сдаче

Составлен 30.09.2026 после аудита. До него определения готовности не было,
и «готово» означало «страница дописана». Из-за этого ни на одном лендинге
не было og-тегов, а мастер-шаблон был беднее клиентских файлов.

Часть пунктов проверяется автоматически хуком `.claude/hooks/deliverable-check.js`
при каждой записи HTML в корне репозитория. Остальное глазами.

## Автоматически (хук не пропустит)

- [ ] Нет незаменённых `{{ПЛЕЙСХОЛДЕРОВ}}`
- [ ] Есть `og:title`, `og:description`, `og:image`
- [ ] Есть `meta viewport` и `meta description`
- [ ] У `<html>` есть `lang`
- [ ] `<title>` заполнен
- [ ] У всех `<img>` есть `alt`
- [ ] Если есть анимации, есть и `prefers-reduced-motion`
- [ ] Медиазапросов больше одного

## Руками, перед отправкой

- [ ] **Проверить, как ссылка выглядит в мессенджере.** Это первое, что увидит
      клиент клиента. og:image должен быть абсолютным URL, не относительным
- [ ] **Открыть на 390px.** Не «сузить окно», а поставить ширину 390 и пройти
      всю страницу. Мобильный это почти весь трафик визитки
- [ ] **Открыть на 1440px.** Проверить, что контент не растянулся в строку
      на весь экран
- [ ] **Нажать каждую ссылку и кнопку.** Телефон звонится, WhatsApp
      открывается, форма отправляется
- [ ] **Счётчик Яндекс.Метрики стоит.** Без него через месяц нечего показать
      клиенту, а значит нет повода для следующего заказа и нет кейса с цифрами
- [ ] **Прочитать первый экран вслух.** За 5 секунд должно быть понятно, что
      продают и куда нажимать

## Правило шаблона

**Улучшение, найденное на клиентском файле, в тот же вечер переносится
в `template.html`.**

Без этого качество не накапливается: аудит показал, что `client-minerva.html`
имел 6 медиазапросов и `prefers-reduced-motion`, а шаблон, из которого
клонируется следующий клиент, имел 1 и ноль. Каждый новый клиент начинался
с худшей версии, чем предыдущий.

## Что проверять у презентации

Отдельный деливерабл, хуком не покрывается.

- [ ] Собрана из шаблона, а не с нуля
- [ ] Есть хотя бы одна схема или диаграмма, а не только текст
- [ ] Шрифты внедрены в файл, иначе у заказчика поедет вёрстка
- [ ] Файл открывается в PowerPoint, а не только в просмотрщике
- [ ] Если работа учебная, оформление сверено с требованиями ГОСТ
