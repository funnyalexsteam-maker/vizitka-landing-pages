# vizitka-landing-pages

Лендинги/визитки под ключ — фриланс-услуга. Дизайн зафиксирован в
`docs/superpowers/specs/2026-09-07-freelance-landing-service-design.md`.

## Структура репозитория

- `template.html` — мастер-шаблон. Копируется под нового клиента без домена.
- `landing.html`, `vizitka.html` — портфолио-демо, опубликованы через GitHub
  Pages, ссылки на них используются в объявлениях.
- `client-<имя>.html` — сайты клиентов без своего домена.
- `sales/` — черновики текста для Avito и Telegram.

Клиенты со своим доменом получают отдельный репозиторий (GitHub Pages
привязывает custom domain на весь репозиторий, не на отдельный файл) — этот
репозиторий для них не используется.

## Как сделать сайт новому клиенту

1. Скопировать `template.html` в `client-<имя>.html`.
2. Заменить все `{{ПЛЕЙСХОЛДЕРЫ}}` реальным контентом клиента (название,
   услуги, контакты). Если у клиента нет готового текста — набросать черновик
   по тому, что он рассказал о бизнесе.
3. Поправить цвета в `:root` под пожелания клиента. Если клиент не хочет
   анимаций — добавить класс `no-anim` тегу `<body>`.
4. Перед сдачей проверить: `grep -o "{{[A-Z0-9_]*}}" client-<имя>.html` не
   должен ничего находить, и глянуть страницу на мобильном и desktop.
5. Закоммитить и запушить — GitHub Pages публикует автоматически (1-2
   минуты).
6. Ссылка на сайт: `https://funnyalexsteam-maker.github.io/vizitka-landing-pages/client-<имя>.html`

Эту работу можно попросить сделать как в Claude Code сессии, так и Jarvis'а
в Telegram — обе схемы работают одинаково (редактирование → коммит → пуш).
