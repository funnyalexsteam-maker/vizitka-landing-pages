# Личные сообщения владельцам малого бизнеса (Instagram / VK)

## Шаблон

```
Здравствуйте! Увидел вашу страницу [название/чем занимаются] —
[что зацепило: товары, оформление, отзывы].

Делаю сайты-визитки/лендинги под ключ для малого бизнеса: одна страница,
адаптив под телефон, публикация включена. Срок 1-2 дня, цена 2000-4000₽.

Если сейчас нет отдельного сайта (или старый пора обновить) — могу
показать примеры и обсудить детали:
https://funnyalexsteam-maker.github.io/vizitka-landing-pages/landing.html
```

## Как использовать — важно

- **Не копировать один в один.** Первую фразу («увидел вашу страницу...»)
  переписывать под каждый профиль — что конкретно зацепило (товар, фото,
  недавний пост). Одинаковый текст веером = выглядит как спам, банят/жалуются.
- **Сначала лёгкий контакт, потом сообщение.** Лайк/комментарий под постом
  перед личкой снижает шанс, что аккаунт пометят как спам-бота — особенно
  в Instagram у новых/непрогретых аккаунтов.
- **Дневной лимит.** Не рассылать десятками за раз в один день — у Instagram
  и VK есть анти-спам пороги на сообщения незнакомым людям, при превышении
  аккаунт может словить временное ограничение на отправку сообщений.
- **Кого искать:** локальный малый бизнес без отдельного сайта — мастера
  (ногти, брови, массаж), небольшие магазины, кафе, репетиторы, частные
  специалисты. Признак — страница есть, сайта в описании профиля нет.
