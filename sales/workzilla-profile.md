# Профиль Workzilla

Готов к вставке. Задача вечера 3 (`Personal/Jarvis/plans/2026-q4-150k.md`, неделя 1).

Workzilla — биржа с бесплатными откликами: [[freelance_marketplace_strategy]] отводит ей роль набора первого кэша и рейтинга в недели 1-3, а не основного канала (Kwork остаётся основным).

## Имя и специализация

При регистрации/в профиле указать специализацию: **Сайты и лендинги, Telegram-боты, оформление документов**.

## О себе (текст для вставки)

```
Разрабатываю сайты, Telegram-ботов и автоматизацию для малого бизнеса, оформляю студенческие работы по ГОСТ.

Делаю так, чтобы работало без меня: бот сам принимает заявки, сайт сам открывается на любом телефоне, документ сам собирается по методичке. Держу несколько собственных сервисов на своём сервере, включая AI-агента, который выполняет задачи по сообщению в Telegram — поэтому разворачивать и поддерживать умею не по учебнику.

Отвечаю быстро, сроки ставлю с запасом и не срываю. Исходники и доступы передаю заказчику полностью.

Что делаю:
— сайты-визитки и лендинги (1-2 дня)
— Telegram-боты: приём заявок, автопостинг, уведомления
— автоматизация рутины, парсинг
— оформление рефератов, курсовых, отчётов по ГОСТ

Примеры работ — в портфолио.
```

## Портфолио для загрузки

Те же 8 позиций, что для Kwork — см. `PORTFOLIO.md`. Ссылки на github.io в текст не вставлять (см. `ISPRAVIT.md`, пункт 3), только фото/скриншоты, если Workzilla позволяет прикрепить файлы к портфолио, а не только к отклику.

## Что делать руками

1. Зарегистрироваться / открыть профиль на Workzilla.
2. Вставить текст "О себе" выше, выбрать специализации из списка.
3. Загрузить портфолио — фото лендингов, скрин диалога с ботом, коллаж презентации.
4. Проверить, есть ли поле "стоимость часа/минимальный чек" — если есть, поставить ориентир от 1000₽, чтобы отсекать заведомо неподходящие заказы.
